## ⚡ Quick Start (No Coding Required)

Want to run this application without installing Python or cloning the source code?
Prerequisites: [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed.

1. **Download the Runner File:**
   ```bash
   curl -o docker-compose.yml https://raw.githubusercontent.com/YOUR-USERNAME/YOUR-REPO/main/docker-compose.prod.yml

2. **Set your API key:**
```bash
# Linux/Mac
export GOOGLE_API_KEY=sk-your-key-here

# Windows PowerShell
$env:GOOGLE_API_KEY="sk-your-key-here"
